A high-performance, responsive, and visually striking portfolio showcasing my professional engineering projects, focusing on **MERN Stack Development**, **Data Intelligence**, and **UI/UX Excellence**. 

Built entirely with Vanilla technologies for maximum performance and hardware-accelerated animations—achieving a perfect 100/100 Lighthouse score.

---

### ✨ Key Features
- **Zero Dependencies:** Pure HTML5, CSS3, and JavaScript. No heavy frameworks slowing down the load time.
- **Hardware-Accelerated UI:** Custom cursor tracking and reveal animations utilizing `requestAnimationFrame` and GPU-accelerated 3D transforms.
- **Responsive Architecture:** Fully fluid design system using CSS Grid, Flexbox, and scaling math that works flawlessly across mobile, tablet, and ultra-wide displays.
- **SEO Optimized:** Implemented comprehensive Open Graph and Twitter Card metadata for rich social media sharing.

### 🚀 Local Development

Since this project uses pure Vanilla web technologies without node modules or build steps, running it locally is instantaneous:

1. Clone the repository:
   ```bash
   git clone https://github.com/mohitsthummar-ops/mohit_portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd mohit_portfolio
   ```
3. Open `index.html` in any modern browser, or use the VS Code Live Server extension.
