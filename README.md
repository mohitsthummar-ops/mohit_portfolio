# Mohit Thummar Portfolio

Professional portfolio website showcasing Web Development (MERN, PHP) and Data Analytics (Power BI) projects.

## 🚀 Deployment Instructions

### 1. Vercel (Recommended)
*   Push your code to a GitHub repository.
*   Import the repository into **Vercel**.
*   Vercel will automatically detect the settings and deploy your site.

### 2. Render
*   Create a new **Static Site** on Render.
*   Connect your GitHub repository.
*   Set **Publish Directory** to: `./` (root).
*   Render will deploy your site instantly.

### 3. GitHub Pages
*   Go to your Repository Settings > Pages.
*   Select the branch (usually `main`) and the root folder `/`.
*   Save, and your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## 🛠 Tech Stack
*   **Frontend**: HTML5, CSS3 (Vanilla), JavaScript
*   **Design**: Modern minimalist, Glassmorphism, Custom Animations
*   **Deployment**: Vercel / Render / GitHub Pages

## 📂 Project Structure
*   `index.html`: Main entry point
*   `style.css`: All styling and animations
*   `main.js`: Interactive elements and reveal effects
*   `public/`: Project images and assets
